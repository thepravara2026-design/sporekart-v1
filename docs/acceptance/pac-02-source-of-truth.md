## 2. Authentication Architecture Specifications

### 2.1 Core Identity & Security Stack
- **Framework:** Spring Security 6.x (Spring Boot 3.4.2) with stateless JWT authentication (`SessionCreationPolicy.STATELESS`).
- **Token Mechanism:** JSON Web Token (HMAC SHA-512) generated by `JwtTokenProvider`.
- **Password Hashing:** `BCryptPasswordEncoder` (strength 10).
- **Authentication Endpoints:**
  - POST `/api/v1/auth/login`: Credential validation, issues `accessToken` (short-lived) and `refreshToken` (rotating).
  - POST `/api/v1/auth/register`: User registration with email normalization.
  - POST `/api/v1/auth/refresh`: Refresh token rotation with token family reuse detection & instant revocation.
  - GET `/api/v1/auth/me`: User identity & assigned roles resolution.

### 2.2 Security Filter Chain Order
1. `RequestIdFilter`: Attaches/propagates `X-Request-ID` tracing header.
2. `JwtAuthenticationFilter`: Parses `Authorization: Bearer <token>`, validates signature & expiration, checks session status in DB, populates `SecurityContextHolder`.
3. `RateLimitingFilter`: Prevents brute-force credential stuffing and API abuse.
4. `UsernamePasswordAuthenticationFilter`: Standard Spring Security filter anchor.

## 4. Frontend Access Control System

- **Auth State Provider:** `AuthProvider` (`frontend/src/context/AuthContext.tsx`) manages token persistence (`localStorage`), token decoding, and current user roles.
- **Route Protection:**
  - `<ProtectedRoute>`: Redirects unauthenticated users to `/login` with location state for post-login return.
  - `<RequireRole roles={[...]}>`: Restricts access to matching roles, redirecting unauthorized roles to `/unauthorized`.
